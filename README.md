# 고2 체육 줄넘기 반납 관리 시스템 (201~208반)

> **교사용 스마트 체육 수업 행정 도구 (Google 스프레드시트 201반~208반 115명 명단 탑재)**  
> 구글 시트의 2학년 체육 반별 명단을 기반으로, 선생님이 상단에서 **반(201~208반)**을 클릭하고 **원하는 날짜**를 지정하여 학생들의 줄넘기 회수 여부를 1번 클릭으로 체크 및 저장할 수 있는 스마트 웹앱입니다.

---

## 📌 주요 핵심 기능

1. **Google 스프레드시트 8개 반(201~208반) 115명 완벽 연동**:
   - 상단 학급 선택 바에서 `[201반]`부터 `[208반]`, 그리고 `[전체 보기]`를 원클릭으로 이동 가능.
   - 각 반 탭마다 **실시간 회수 현황 뱃지(예: `10/12명 (83%)`, 전원 완료 시 `✓ 전원완료`)**가 표시됩니다.
2. **날짜별 회수 여부 추적 및 달력 이동**:
   - `[◀ 어제]`, `[오늘]`, `[내일 ▶]` 빠른 이동 버튼 및 달력 Date Picker 지원.
   - 지난 날짜(어제, 지난주 등)를 선택하면 해당 일자에 기록되었던 회수 상태와 미회수 학생이 즉시 화면에 복원됩니다.
3. **체육 교사를 위한 초고속 반납 체크**:
   - **1-클릭 토글**: 학생 행의 `[회수 완료 ✓]` / `[미회수 ⏳]` 버튼을 탭하면 0.01초 만에 즉시 상태 전환 및 카운터 동기화.
   - **반 전원 일괄 회수 버튼**: 수업 종료 직후 `[✨ {선택반} 전원 회수 완료]` 버튼을 누르면 해당 반 전체 학생이 한 번에 회수 완료 처리됩니다.
4. **실시간 3단 요약 대시보드**:
   - **선택 학급 회수 현황**: 선택한 반의 출석 인원 중 줄넘기를 낸 학생 수 및 회수율 프로그레스 바.
   - **선택 학급 미회수 인원**: 아직 줄넘기를 반납하지 않은 대기 인원 수 (선생님이 수업 끝에 즉시 파악 가능).
   - **고2 전체 8개 반 총 회수율**: 선택한 날짜에 학년 전체 115명 중 총 몇 명이 반납했는지 한눈에 집계.
5. **Apple 스타일의 미니멀 프리미엄 디자인**:
   - 액션 블루(`#0066cc`), 양피지 캔버스(`#f5f5f7`), 순백색 유틸리티 카드, 섬세한 헤어라인 테두리 적용.
6. **학교 개인정보보호 및 심의 완벽 준수**:
   - 교사 단말기 내부 원자적 저장(Atomic File Write) 및 실시간 감사 로그(Audit Log).
   - 푸터 필수 링크(개인정보 처리방침, 이용약관, 책임자 연락처, 기관명, 시행일자) 내장.

## 💡 선생님 수업 현장 활용 팁

1. **수업 시작 전 반 선택**: 상단의 `[201반]`, `[202반]`... 중 지금 수업하는 반 버튼을 탭합니다.
2. **날짜 확인**: 날짜 바가 오늘 날짜(예: 2026-10-28)로 되어 있는지 확인합니다. 지난 수업을 확인하려면 `[◀ 어제]`를 누르거나 달력을 클릭합니다.
3. **아이들이 줄넘기를 가져올 때**: 해당 학생의 `[미회수 ⏳]` 버튼을 톡 누르면 즉시 **초록색 `[회수 완료 ✓]`**로 바뀌며 상단 회수 인원이 즉시 올라갑니다.
4. **수업 끝나고 한 번에 체크할 때**: `[✨ {선택반} 전원 회수 완료]` 버튼을 누르면 1초 만에 반 전체가 회수 완료로 처리됩니다.
5. **미반납 학생 파악**: 상단 주황색 카드의 `미회수 학생` 숫자를 보거나, 필터에서 `미회수` 탭을 누르면 아직 안 낸 학생만 모아볼 수 있습니다.
