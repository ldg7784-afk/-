# Firebase Cloud Firestore (Spark 무료 플랜) 완벽 연동 가이드

본 가이드는 **고2 체육과 줄넘기 반납 관리 시스템**을 Google Firebase의 **Spark(무료) 플랜**을 통해 클라우드 데이터베이스(Cloud Firestore)와 연동하는 방법을 단계별로 안내합니다.

---

## 💡 1. Spark(무료) 플랜이란? (완전 무료 보장)

Google Firebase의 **Spark 플랜**은 전 세계 개발자와 교육기관에 무료로 제공되는 기본 요금제입니다.

| 항목 | Spark 무료 플랜 제공량 | 본 줄넘기 웹앱 하루 예상 사용량 | 여유율 |
| :--- | :--- | :--- | :--- |
| **신용카드 등록** | **등록 불필요 (0원 보장)** | - | 결제 수단 없이 사용 가능 |
| **일일 문서 읽기 (Reads)** | **50,000 회 / 일** | 약 30 ~ 80 회 / 일 (메모리 캐시 적용) | **99.8% 여유** |
| **일일 문서 쓰기 (Writes)** | **20,000 회 / 일** | 약 115 회 / 일 (전교생 반납 체크 시) | **99.4% 여유** |
| **일일 문서 삭제 (Deletes)** | **20,000 회 / 일** | 0 ~ 10 회 / 일 | **99.9% 여유** |
| **무료 저장 공간 (Storage)** | **1 GiB (약 1,024 MB)** | 약 1.5 ~ 3 MB (115명 명단 및 1년 치 기록) | **99.7% 여유** |

> 📌 **과금 걱정 제로 (Zero Cost)**  
> Spark 플랜은 한도를 초과하더라도 추가 요금이 결제되는 것이 아니라 당일 요청이 잠시 차단되는 구조이므로, **의도치 않은 과금이 1원도 발생하지 않습니다.**  
> 더욱이 본 시스템은 서버 메모리 캐싱 기술이 적용되어 있어 전교생 115명을 매일 체크해도 무료 한도의 1% 미만만 사용합니다.

## 🛠️ 2. 단계별 연동 방법 (6단계)

### [1단계] Firebase 콘솔에서 무료 프로젝트 생성하기
1. 웹 브라우저에서 **[Firebase 콘솔](https://console.firebase.google.com)** 에 접속합니다.
2. Google 계정(학교 계정 또는 개인 구글 계정)으로 로그인합니다.
3. 화면 중앙의 **[+ 프로젝트 만들기]** (또는 프로젝트 추가) 버튼을 클릭합니다.
4. 프로젝트 이름을 입력합니다. (예: `jumprope-pe-class`)
5. Google 애널리틱스 설정 단계가 나오면 **체크 해제(사용 안함)** 를 권장합니다. (체육 교구 관리이므로 애널리틱스가 불필요하며 생성 속도가 빨라집니다.)
6. **[프로젝트 만들기]** 버튼을 누르고 10~20초 후 생성이 완료되면 **[계속]** 을 누릅니다.

---

### [2단계] Cloud Firestore 데이터베이스 생성하기
1. 왼쪽 사이드바 메뉴에서 **[빌드(Build)]** 를 펼치고 **[Firestore Database]** 를 클릭합니다.
2. 화면 중앙의 **[데이터베이스 만들기]** 버튼을 클릭합니다.
3. **데이터베이스 위치(Location)** 선택:
   - 목록에서 **`asia-northeast3 (Seoul)`** (서울 리전)을 선택합니다.  
   *(서울을 선택해야 국내에서 데이터 읽기/쓰기 속도가 가장 빠릅니다.)*
4. **보안 규칙(Security rules)** 선택:
   - 본 시스템은 Node.js 서버의 비공개 인증 키(Admin SDK)를 통해 보안 통신하므로 **프로덕션 모드** 또는 **테스트 모드** 중 아무거나 선택하셔도 안전하게 동작합니다. (프로덕션 모드 권장)
5. **[만들기]** (또는 사용 설정)를 클릭하면 수 초 내에 데이터베이스가 준비됩니다.

---

### [3단계] 비공개 서비스 계정 키(JSON) 발급받기
1. Firebase 콘솔 화면 좌측 상단 메뉴의 **톱니바퀴 아이콘 ⚙️** → **[프로젝트 설정]** 을 클릭합니다.
2. 상단 탭 메뉴 중 **[서비스 계정(Service accounts)]** 탭을 클릭합니다.
3. Node.js 항목이 선택된 상태에서 하단의 **[새 비공개 키 생성(Generate new private key)]** 버튼을 클릭합니다.
4. 안내 팝업창에서 **[키 생성]** 을 누르면 컴퓨터의 다운로드 폴더에 `.json` 파일이 다운로드됩니다.  
   *(예: `jumprope-pe-class-firebase-adminsdk-xxxxx-xxxxxxxxxx.json`)*

---

### [4단계] 키 파일 이름 변경 및 프로젝트 폴더에 넣기
1. 다운로드된 긴 파일의 이름을 정확히 아래와 같이 변경합니다:
   ```text
   serviceAccountKey.json
   ```
2. 이 `serviceAccountKey.json` 파일을 현재 프로젝트 루트 폴더에 넣습니다:
   - 폴더 위치: `c:\Users\user\Desktop\vibe sample\`
   - (즉, `server.js`, `package.json` 과 같은 위치에 넣어주시면 됩니다.)

> 🔒 **보안 안전장치**  
> `serviceAccountKey.json` 파일은 이미 `.gitignore` 에 등록되어 있어, 깃허브나 외부에 실수로 업로드되지 않도록 완벽히 보호됩니다. 또한 웹 브라우저 클라이언트가 아닌 Node.js 서버 내부에서만 격리되어 안전하게 사용됩니다.

---

### [5단계] 기존 115명 명단 및 기록 Firestore로 일괄 올리기 (1회 실행)
구글 시트에서 불러온 201반~208반 115명 학생 명단과 기존 기록을 클라우드 Firestore로 한 번에 업로드합니다.

1. VS Code 또는 PowerShell 터미널을 엽니다.
2. 아래 명령어를 실행합니다:
   ```bash
   node migrate_to_firestore.js
   ```
3. 터미널에 아래와 같이 성공 메시지가 출력됩니다:
   ```text
   ====================================================
     Firestore 데이터 마이그레이션 시작 (Spark 무료 플랜)
   ====================================================
   총 115명 학생 및 반납 기록을 Firestore로 업로드합니다...
   ✅ 마이그레이션 완료!
      - 학생: 115명
      - 반납 기록: 정상 동기화 완료
      - 이제 웹앱이 Firebase Firestore와 실시간 연동되어 동작합니다.
   ====================================================
   ```

---

### [6단계] 연동 완료 확인 및 실시간 사용
1. 웹앱(`http://localhost:3000`)에 접속합니다.
2. 상단 바에 다음과 같은 뱃지가 표시되는지 확인합니다:
   - **`🔥 Firestore 연동됨`** (초록색 불빛)
3. 상단의 **[🔥 Firebase 연동]** 버튼을 누르면 열리는 창에서 **[🔄 연결 상태 실시간 확인]** 버튼을 눌러 언제든지 연결 상태와 Spark 무료 플랜 쿼터를 점검할 수 있습니다.
4. 이제 학생의 반납 상태(`[회수 완료 ✓]` / `[미회수 ⏳]`)나 일괄 완료 버튼을 누를 때마다 Google Cloud Firestore 클라우드에 0.1초 만에 실시간 저장됩니다.

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 키 파일 등록 전에도 웹앱을 사용할 수 있나요?
**네, 가능합니다.**  
`serviceAccountKey.json` 파일이 없더라도 시스템이 자동으로 로컬 고속 DB(`data/db.json`) 모드로 동작하므로 수업 중에 문제없이 줄넘기를 체크하고 저장할 수 있습니다. 키 파일을 넣는 순간 언제든지 클라우드 모드로 자동 전환됩니다.

### Q2. 인터넷이 잠시 끊기거나 불안정하면 어떻게 되나요?
서버에 원자적(Atomic) 로컬 미러링 기술이 탑재되어 있어 로컬에 즉시 기록된 후 백그라운드로 Firestore에 안전하게 동기화되므로 데이터가 유실되지 않습니다.

### Q3. 학생 수가 늘어나도 무료인가요?
Spark 무료 플랜은 하루 20,000번의 쓰기와 50,000번의 읽기를 제공합니다. 학교 전체 학생이 1,000명으로 늘어나더라도 하루 1,000회 쓰기에 불과하므로 무료 한도(20,000회)의 5%에 불과하여 영구 무료로 사용 가능합니다.
