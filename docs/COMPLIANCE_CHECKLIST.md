# [심의 대응] 학습지원 소프트웨어 심의 대응 체크리스트 및 설정 가이드

> 학교 현장에서 교육청 '학습지원 소프트웨어 심의' 및 '개인정보보호 영향평가' 준비 시 담당 교사 및 행정 부서가 즉시 활용할 수 있도록 작성된 자체 점검표입니다.

---

## 1. 소프트웨어 사용 목적 구분 및 설정

본 시스템은 시도교육청 심의 가이드라인에 따라 3가지 사용 목적 중 하나를 선택할 수 있으며, 기본값은 **[교사 단독 행정·업무용]**으로 설정되어 있습니다.

| 구분 | 목적명 | 상세 설명 | 개인정보 심의 난이도 |
| :--- | :--- | :--- | :--- |
| **유형 1 (기본 권장)** | **교사 단독 행정·업무용** | 교사 단말기에서 교사만 조작. 학생은 별도 회원가입이나 계정 생성 없이, 교사가 교구 반납 여부만 대조·체크 | **가장 간소함** (학생 계정 미생성, 개인정보 침해 우려 최소) |
| **유형 2** | **정규 수업 학생 사용** | 체육관 내 공용 태블릿 PC 등을 비치하여 학생이 직접 본인의 학번/이름을 선택해 반납을 체크하는 방식 | 중간 (단말기 내 타 학생 정보 열람 통제 필요) |
| **유형 3** | **가정 및 과제 연계용** | 방과 후 줄넘기 연습 과제 확인 또는 가정 연계 활동 기록 관리 | 보통 (가정 접속 환경 및 권한 관리 필요) |

---

## 2. 시도교육청 심의 기준별 자체 점검 체크리스트

### 가. 개인정보 수집 및 처리의 최소성 (Pass)
- [x] **민감정보 배제**: 주민등록번호, 생체인식정보, 종교, 건강정보 등 일체의 민감정보를 수집하지 않음.
- [x] **비밀번호 미보관**: 학생 회원가입 절차가 없으므로 학생 비밀번호를 저장하거나 요구하지 않음.
- [x] **가명/익명 처리 지원**: 학생 이름 수집을 원치 않을 경우 학번 단독 또는 `학생(10101)` 형태의 가명 처리가 가능한 '개인정보 최소수집 모드' 기본 내장.
- [x] **목적 외 이용 방지**: 수집된 데이터는 '줄넘기 반납 여부 확인 및 분실 방지' 이외의 어떠한 용도로도 활용되지 않음.

### 나. 안전성 확보조치 및 보안 (Pass)
- [x] **접근 권한 통제**: 환경변수(`TEACHER_ACCESS_CODE`) 기반 교사 보안 인증 통제 구현.
- [x] **서버 검증(Server-side Validation)**: 클라이언트 화면 조작과 무관하게 백엔드 서버에서 필수값(학번, 이름, 반납 여부) 및 문자열 길이를 강제 검증.
- [x] **원자적 저장(Atomic File I/O)**: 임시 파일 생성 후 rename 방식을 적용하여 서버 강제 종료 시에도 데이터베이스 손상 방지.
- [x] **감사 로그(Audit Trail)**: 데이터 등록, 수정, 삭제, 백업 다운로드 및 로그인 시도 내역을 일시·IP와 함께 실시간 보관.

### 다. 데이터 주권 및 파기·백업 계획 (Pass)
- [x] **정기 자동 백업**: 서버 기동 및 주요 변경 시 `data/backups/`에 타임스탬프 기반 JSON 백업본 최대 20개 회전 보관.
- [x] **관리자 백업 다운로드**: 교사가 언제든지 웹 화면에서 클릭 한 번으로 `jumprope_backup.json` 다운로드 가능.
- [x] **오류 수정 및 파기권 보장**: 학생 개별 삭제 버튼(`🗑️`) 및 오늘 기록 일괄 초기화 버튼 제공으로 정보주체의 삭제 요구 즉각 대응 가능.
- [x] **보유 기간**: 학년도 종료(기본 1년) 시 데이터 일괄 폐기 원칙 준수.

### 라. 투명성 및 정책 고지 (Pass)
- [x] **푸터 링크 상시 노출**: 메인 화면 하단에 개인정보 처리방침, 이용약관, 책임자 연락처, 기관명, 시행일 명시.
- [x] **모달 팝업 전문 뷰어**: 별도 페이지 이동 없이 팝업으로 누구나 약관 및 방침 원문을 열람 가능.

## 3. 심의 제출용 한 줄 요약서 (복사용)

> **"본 소프트웨어는 체육 수업 시간 내 교구(줄넘기)의 반납 여부를 확인하기 위하여 교사가 단독으로 사용하는 경량 행정 보조 웹앱입니다. 학생 계정 생성이나 민감정보 수집이 전혀 없으며, 학번 기반 식별 및 가명 처리를 기본 지원하고, 데이터는 교내 관리 서버에만 암호화/원자적으로 안전하게 저장되므로 학생 개인정보 침해 가능성이 극히 낮습니다."**
