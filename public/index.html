🎉 Spark 플랜: 100% 영구 무료 (카드 등록 불필요)
구글 Firebase의 Spark 플랜은 신용카드 등록 없이 완전 무료로 제공됩니다.
• 일일 읽기 50,000회 / 쓰기 20,000회 / 저장공간 1 GiB 무료
• 본 웹앱은 고속 메모리 캐시 최적화로 하루 전체를 써도 일일 200회 미만(무료 한도의 1% 미만)만 사용하여 요금이 전혀 발생하지 않습니다.
1

Firebase 콘솔 무료 프로젝트 생성

브라우저에서 Firebase 콘솔 (console.firebase.google.com)에 접속하여 구글 계정으로 로그인한 뒤 [프로젝트 추가]를 누릅니다.

프로젝트 이름(예: jumprope-pe)을 입력하고 완료합니다. (Google 애널리틱스는 체크 해제 권장)

2

Cloud Firestore 데이터베이스 만들기

좌측 메뉴에서 [빌드] → [Firestore Database] 클릭 후 [데이터베이스 만들기]를 누릅니다.

위치는 가장 빠른 서울 리전 asia-northeast3 (Seoul)을 선택하고 [만들기]를 완료합니다.

3

서비스 계정 비공개 키(JSON) 발급

화면 좌측 상단 톱니바퀴 ⚙️ 아이콘 → [프로젝트 설정]을 클릭한 뒤, 상단 [서비스 계정] 탭을 선택합니다.

하단의 [새 비공개 키 생성] 버튼을 누르면 JSON 인증 키 파일이 내 컴퓨터로 다운로드됩니다.

4

키 파일 이름 변경 후 프로젝트 폴더에 넣기

다운로드된 파일(예: xxxx-firebase-adminsdk-xxxx.json)의 이름을 정확히 serviceAccountKey.json 으로 변경합니다.

이 파일을 현재 웹앱 프로젝트 폴더(vibe sample) 바로 안에 붙여넣습니다.

5

학생 명단(115명) Firestore 일괄 업로드

키 파일을 넣은 후 터미널(PowerShell)에서 아래 명령어를 한 번 실행하면 구글 시트에서 가져온 115명 명단과 기존 기록이 Firestore로 자동 전송됩니다:

node migrate_to_firestore.js
6

연동 완료 및 자동 동기화

위의 [🔄 연결 상태 실시간 확인] 버튼을 누르면 서버 재시작 없이 즉시 Firestore 연결이 활성화됩니다!
