# Project Rules & Agent Guidelines

## Autonomous Execution
- **Minimize unnecessary questions**: Do not ask for user confirmation or approval before performing standard development tasks, creating files, or writing code.
- **Proactive problem solving**: Pick the optimal and modern approach directly, implement the solution, and present the result.
- **Complete workflows**: When asked to implement or fix something, carry out the full lifecycle (analyze -> create/modify -> test/validate) autonomously.
